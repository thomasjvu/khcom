# Maho — starter character artwork

Adult original character with long straight black hair, a white maid headband,
black dress, white apron and rear bow, white stockings and black Mary Janes.

`starter-sheet-v1.png` is a transparent 20-pose art draft: five columns
(idle plus four proposed walking poses), four rows (front right, back right,
front left, back left). Generated using the built-in image generation tool;
the exact prompt is in `generation-prompt.txt`.

References: the pink-ponytail custom sheet and original Kairi sprite sheet.
This is not yet ROM-importable: clean up on a native pixel grid, normalize
frame anchors, reduce to 15 opaque GBA colors plus transparency, define OBJ
pieces and animation timings, and add controller-required action poses.
See `../pink-ponytail/README.md` for the production conversion workflow.
